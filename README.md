\## Tech Stack

\- \*\*Frontend:\*\* React.js, Chart.js, HTML5, CSS3

\- \*\*Backend:\*\* Node.js, Express.js, JWT, Twilio SMS

\- \*\*Database:\*\* PostgreSQL 18

\- \*\*ML:\*\* XGBoost, TensorFlow LSTM, Flask, scikit-learn

\## How to Run



```bash

\# Clone

git clone https://github.com/rishukoder/smart\_health\_monitor.git

cd smart\_health\_monitor



\# Start everything (Windows)

start\_project.bat

```
